# Weighted AM–GM

Prerequisites: AM-GM, weighted averages, positive real exponents, normalized weights.

For xi>0, lambda_i>=0, sum lambda_i=1:

sum(lambda_i xi) >= product(xi^lambda_i).

With positive weights, equality occurs when the corresponding xi are equal.

Two-variable form:
lambda x + (1-lambda)y >= x^lambda y^(1-lambda).

Olympiad form with lambda=2/3:
2x+y >= 3(x^2 y)^(1/3).

Recognition cues:
- target monomial has unequal exponents;
- coefficients are unequal;
- choose weights to reproduce exponents;
- homogeneous term-by-term matching.

Misconceptions:
- MIS-WAMGM-01: weights do not sum to one.
- MIS-WAMGM-02: arithmetic coefficients and geometric exponents do not match.
- MIS-WAMGM-03: negative weights.
- MIS-WAMGM-04: equality condition ignored.

Connection to Jensen:
log is concave, so Jensen on log gives Weighted AM-GM.
