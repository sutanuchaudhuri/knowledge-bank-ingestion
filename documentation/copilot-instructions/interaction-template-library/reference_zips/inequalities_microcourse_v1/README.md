## Non-negotiable video rule

A curated YouTube URL is NOT enough for learner-time question answering.

For a video state to be publishable with "pause and ask" enabled, it must have:
1. approved provider/video ID,
2. approved timestamped transcript,
3. approved transcript segments,
4. segment -> Concept / Technique / Skill / Misconception annotations,
5. fixed quiz/intervention markers where needed.

If the actual transcript has not been imported and human-reviewed:
- student_questioning_enabled = false
- publication_validation = BLOCKED_FOR_INTERACTIVE_VIDEO

The anchor YouTube video exposes reliable chapter timestamps in its public description,
but its full captions were not accessible to this build. Therefore chapter windows are
persisted, authored companion explanations are included, actual transcript text is left
null, and publication remains blocked until the admin transcript importer obtains and
approves the real captions.
