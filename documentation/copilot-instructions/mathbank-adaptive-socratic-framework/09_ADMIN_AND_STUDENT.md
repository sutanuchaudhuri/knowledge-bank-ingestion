# 09 — Human-centered authoring and learner UX

## Admin Socratic Studio
Catalog filters: domain/subdomain/strategy/problem/review status, source/structural/discovery/human quality separately. Designer canvas: START, discovery, quiz, assertion-reason, geometry interaction, AI decision, deterministic gate, remediation, return, transfer, complete. Click a node → focused inspector: objective, source claim, current prompt, activity/rubric, hints H1–H5, allowed visual before/after, transition conditions, accessible alternate, audit/diff. Add, remove, split, merge, branch and reorder only on DRAFT with validation of every dependent reference. Previous/Next stepper for content; workflow canvas for navigation, not endless single page.

AI co-author panel: choose propose missing discoveries / split overloaded step / diversify quizzes / candidate branch / diagnostic distractors / leakage audit. Show reviewable patch diff, source citations, mathematical critic status, risk and predicted cost. Explicit Accept/Edit/Reject per proposed change; no automatic apply or publish. Review cockpit has structural checks, mathematical attestation, pedagogical attestation, student-mode preview, simulation traces, release hash and signed decision. Preview must call same sanitized runtime endpoint with test ownership, not separate mock renderer.

## Student UI
One task per screen: question and safe current scene; predict/construct/respond; optional approved hint/reveal; approved feedback; previous/review for completed nodes; locked future nodes; explicit current progress and optional independent/challenge mode. Quiz formats mixed and responsive. Socratic reveal records assisted path, never shames or falsely confers independent mastery. Alternative valid proof branch through reviewed claim mapping. Transfer checkpoint before claiming strong comprehension. Gamification awards discovery, verification, revision, alternate reasoning and transfer as optional encouragement, not addictive speed streaks or raw mastery.

## Accessibility and data
Keyboard-first graph and quiz interactions, math readable and announced, color not sole indicator, reduced-motion fallback, accessible explanation of interactive geometry constraints. Minors: minimal retention and instructor analytics aggregation, scoped admin transcript review, no learner private responses in global graph.
