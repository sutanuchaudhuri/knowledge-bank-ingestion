# Markov Chains — Competition Mathematics Track

## 1. What makes a process Markov?

Let X_n denote the state after n steps. The Markov property says

P(X_{n+1}=j | X_n=i, X_{n-1},...,X_0)
=
P(X_{n+1}=j | X_n=i).

The future does not need the entire path once the *correct current state* is known.

This does **not** mean the physical process has no history. It means that the state
description contains all history that matters for predicting the next step.

### Competition insight
The hardest step is often not probability arithmetic. It is designing the state.

For the 2019 AMC 10B #22 / AMC 12B #19 money-transfer game, all ordered distributions
of three dollars collapse into two behaviorally distinct state types:
- A = (1,1,1)
- B = a permutation of (2,1,0)

That state compression turns a large-looking 2019-step process into a 2-state chain.

## 2. State graph

A state graph has:
- one node per state;
- a directed edge i -> j when j can occur next from i;
- edge label P(i->j).

For a valid discrete transition model, outgoing probabilities from each state sum to 1.

### Misconception MC-M01
A graph node should not represent "what just happened" unless that information changes
future transition probabilities. Store only sufficient state.

## 3. Transition matrix

For states s1,...,sk, define

P_ij = P(next state = sj | current state = si).

Using row-vector convention:

mu_(n+1) = mu_n P,
mu_n = mu_0 P^n.

Every row of P sums to 1.

### Misconception MC-M02
Do not mix row-vector and column-vector conventions mid-solution.

## 4. First-step recursion

Suppose h_i is the probability of eventually reaching a success state S before failure F,
starting from state i.

Then for a nonterminal state i:

h_i = sum_j P_ij h_j.

Boundary values:
h_S = 1,
h_F = 0.

This is simply the law of total probability applied to the first step.

### Why this is competition-important
You usually do **not** need a formal matrix inverse.
Write one equation per meaningful state and solve the resulting small linear system.

The 2025 AMC 12B #20 frog problem is a perfect model:
define p_n = probability of eventually reaching 4 from n. The recursion is generated by
conditioning on the first move.

## 5. Expected hitting time

Let E_i be the expected number of additional steps to absorption from transient state i.

Then:

E_i = 1 + sum_j P_ij E_j

for nonterminal i, with E_terminal = 0.

The extra 1 counts the step you are about to take.

### Misconception MC-M03
Students often write only the weighted future expectations and forget the leading +1.

## 6. Absorbing chains

An absorbing state cannot be left.

After reordering transient states first and absorbing states last, the matrix has form

P = [ Q  R
      0  I ].

The competition-level idea is more important than the notation:
- transient states keep the process moving;
- absorbing states encode completed outcomes;
- first-step equations determine absorption probabilities.

The fundamental matrix (I-Q)^(-1) is useful later, but is not required for most
AMC/AIME/HMMT solutions.

## 7. Symmetry and state compression

Before writing equations, ask:

1. Which configurations have identical future behavior?
2. Can states be grouped by distance, parity, number of tokens, or symmetry class?
3. Does the exact label of a person/vertex matter, or only the type of configuration?

### Example: 2020 AMC 10A #13
The frog moves on a 4x4 square lattice until hitting a boundary.
Symmetry reduces the many interior points to only a few distinct probability values.

## 8. Recurrence viewpoint

Sometimes the Markov chain collapses to a one-variable recurrence.

For 2003 AIME II #13, let p_n be the probability that the bug is at its starting vertex
after n moves around a triangle.

Then

p_(n+1) = (1/2)(1-p_n).

Subtract the fixed point 1/3:

p_(n+1)-1/3 = -(1/2)(p_n-1/3),

so the deviation is geometric.

This is simultaneously:
- a Markov chain,
- a recurrence,
- a fixed-point/convergence problem.

## 9. Stationary distribution

A probability row vector pi is stationary if

pi P = pi,
sum_i pi_i = 1.

If the chain begins in pi, one transition leaves the distribution unchanged.

For a finite irreducible aperiodic chain, the long-run distribution converges to the unique
stationary distribution.

### Competition warning
"Stationary" and "eventual limit from every starting state" are related but are not identical
statements without hypotheses such as irreducibility/aperiodicity.

### Misconception MC-M04
Solving pi P=pi does not by itself prove convergence from every initial distribution.

## 10. Periodicity

A chain may possess a stationary distribution but oscillate instead of converging to it
from a chosen initial state.

The simplest example is a two-state chain that alternates deterministically:
A -> B -> A -> B -> ...

Its stationary distribution is (1/2,1/2), but starting at A gives alternating point masses.

## 11. Competition workflow

When a repeated random process appears:

1. Define the exact target event.
2. Identify the smallest sufficient state.
3. Merge symmetric/equivalent configurations.
4. Draw the state graph.
5. Label transition probabilities.
6. Decide:
   - direct one-step conditioning?
   - first-step recursion?
   - n-step recurrence?
   - matrix power?
   - stationary distribution?
7. Set boundary/initial conditions.
8. Solve.
9. Verify:
   - probabilities stay in [0,1],
   - transition rows sum to 1,
   - symmetry conditions are respected.

## 13. Misconception catalog

MC-M01 — state carries too much or too little history.
MC-M02 — row/column transition convention mixed.
MC-M03 — expected-time recurrence omits +1.
MC-M04 — stationary distribution confused with guaranteed convergence.
MC-M05 — probabilities on outgoing edges do not sum to 1.
MC-M06 — absorbing boundary assigned wrong value.
MC-M07 — paths enumerated independently even though states are revisited.
MC-M08 — symmetry merges states whose transition behavior is actually different.
MC-M09 — P^n confused with elementwise powers.
MC-M10 — target "on the nth step" confused with "by the nth step".
