# Polynomial Resource Library v1

Deterministic micro-course library for:
- Vieta's formulas
- quadratic equations
- cubic polynomials
- biquadratic / quartic structure
- higher-degree polynomials

The resource library is grounded to the user's `Tika Competition Math Master Question Corpus`
for competition-problem IDs and taxonomy mappings.

## Important taxonomy rule
The corpus currently has canonical `ALG_QUAD`, `ALG_POLY`, `ALG_VIETA`, and Vieta
sub-techniques. It does not currently expose separate canonical cubic/quartic/biquadratic
nodes. Those names are course modules mapped to existing nodes, not newly invented graph IDs.

## External video rule
External YouTube resources are curated but remain `PENDING_IMPORT` until actual captions
are imported, timestamped, semantically annotated, human-reviewed, and approved.
Until then, "Ask about this moment" is disabled.

## Original Manim
The included Manim storyboard/scripts are original authored resources. After rendering,
their actual timestamps can be reconciled with the authored narration and made fully
questionable because the transcript is owned/prepared in advance.
