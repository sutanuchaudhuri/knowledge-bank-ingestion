# Jensen's Inequality

Prerequisites: functions, domains, weighted averages, convex/concave functions,
derivative tests for convexity/concavity, monotonic transformations.

If f is convex and lambda_i>=0 with sum lambda_i=1:

f(sum lambda_i x_i) <= sum lambda_i f(x_i).

For concave f, reverse the inequality.

For strictly convex f with positive weights, equality occurs when all xi are equal.

Geometry:
a convex graph lies below each chord; a concave graph lies above it.

AM-GM connection:
use concave f(x)=log x on x>0.

Recognition cues:
- sum f(x_i);
- fixed mean;
- one function repeated on several variables;
- easy convexity/concavity on the entire interval.

Misconceptions:
- MIS-JENSEN-01: reversing convex/concave direction.
- MIS-JENSEN-02: checking convexity only at one point.
- MIS-JENSEN-03: weights not normalized.
- MIS-JENSEN-04: ignoring the domain (especially log).
