# Visual State Model

Visual state properties:

```text
visible
opacity
emphasis
stroke_weight_class
line_style
label_visible
highlight_group
dimmed
z_index
render_mode
```

Example:

```json
{
  "entity_id": "circle_Gamma",
  "visible": true,
  "emphasis": "BACKGROUND",
  "stroke_weight_class": "THIN",
  "opacity": 0.35
}
```

Pedagogical visibility is separate from mathematical truth:

```text
knowledge_status = GIVEN
visibility_status = HIDDEN_UNTIL_STEP_3
```
