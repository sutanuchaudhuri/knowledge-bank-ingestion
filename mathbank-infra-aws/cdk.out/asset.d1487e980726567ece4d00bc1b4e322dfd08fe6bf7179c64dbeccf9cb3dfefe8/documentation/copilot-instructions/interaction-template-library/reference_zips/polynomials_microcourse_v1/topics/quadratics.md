# Quadratic Equations

## Canonical mapping
- `ALG_QUAD`
- related `ALG_VIETA`, `ALG_POLY`.

## Prerequisites
Factoring; completing the square; square roots; graph of a parabola; Vieta.

For ax^2+bx+c=0, a!=0:
discriminant Δ=b^2-4ac.

Over the reals:
- Δ>0: two distinct real roots.
- Δ=0: one repeated real root.
- Δ<0: two nonreal conjugate roots.

Roots:
x=(-b±sqrt(Δ))/(2a).

Vieta:
r1+r2=-b/a, r1r2=c/a.

## Competition habits
Before expanding:
1. Ask whether only sum/product of roots is needed.
2. Check whether a substitution turns the problem quadratic.
3. Use discriminant conditions for repeated/integer/real-root constraints.
4. For compositions like P(P(x)), work from outer roots inward.

## Misconceptions
- QUAD-M01: discriminant sign interpreted incorrectly.
- QUAD-M02: leading coefficient omitted from Vieta.
- QUAD-M03: repeated root counted as only one algebraic root.
- QUAD-M04: extraneous roots after substitution not checked.
- QUAD-M05: solving a composition by brute-force expansion before using structure.
