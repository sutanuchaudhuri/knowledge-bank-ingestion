# AM–GM

Prerequisites: positive/nonnegative reals, arithmetic/geometric means, exponents/roots,
factorization, equality-condition reasoning.

For positive reals x1,...,xn:

(x1+...+xn)/n >= (x1...xn)^(1/n).

Equality iff x1=...=xn.

For x,y>0:
(x+y)/2 >= sqrt(xy).

Proof idea:
(sqrt(x)-sqrt(y))^2 >= 0.

Recognition cues:
- fixed sum -> maximize product;
- fixed product -> minimize sum;
- positive symmetric terms;
- equality likely at equal variables.

Example:
x+y=12 -> sqrt(xy)<=6 -> xy<=36, equality x=y=6.

Misconceptions:
- MIS-AMGM-01: using standard AM-GM on negative inputs.
- MIS-AMGM-02: forgetting the equality condition.
- MIS-AMGM-03: wrong number of terms/root.
- MIS-AMGM-04: forcing equal coefficients when Weighted AM-GM is appropriate.
