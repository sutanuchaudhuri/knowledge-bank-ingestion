# Video Q&A policy for Markov course

External YouTube:
- may be displayed if admin-curated;
- may NOT enable "Ask about this moment" without an approved timestamped transcript.

At pause time t:
1. persist course state and t;
2. resolve one approved transcript segment containing t;
3. load segment text + Concept/Technique/Skill/Misconception bindings;
4. permit explanation only inside approved local context plus explicitly linked prerequisites;
5. if a misconception is detected, launch only a predetermined intervention;
6. restore exact video timestamp afterward.

If transcript is unavailable:
VIDEO_TRANSCRIPT_NOT_APPROVED
student_questioning_enabled=false

PROB_MARKOV
PROB_MARKOV_MATRIX
TECH_STATE_GRAPH
PROB_COND
PROB_EXP
COUNT_REC
ALG_MATRIX
