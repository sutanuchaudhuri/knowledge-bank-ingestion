# Markov Chains for Competition Mathematics — Deterministic Micro-Course v1

This library is designed for the same semi-deterministic tutor architecture as the
inequality and polynomial packs.

Primary canonical nodes already present in the user's corpus:
- PROB_MARKOV — Probability > Markov Chains
- PROB_MARKOV_MATRIX — Transition matrix / Markov matrix
- TECH_STATE_GRAPH — finite-state / state-graph modeling
- PROB_COND — conditional probability
- PROB_EXP — expected value
- COUNT_REC — recurrences
- ALG_MATRIX — matrix methods

The course does not require matrices at the beginning. Competition students first learn
state compression and first-step recursion; matrices are introduced as a second
representation of the same state model.

## Three assessment layers
1. PRE diagnostic — prerequisites before Markov chains
2. INTERMEDIATE checkpoints — after state modeling / after hitting probabilities / after matrices
3. POST transfer — new contest-style models and technique selection

## External YouTube safety
Every external video remains `TRANSCRIPT_PENDING_IMPORT` until the actual captions are
imported, timestamped, semantically annotated, reviewed and approved. Until then,
`student_questioning_enabled=false`.

Public video descriptions may be used to decide *why* a video is curated, but never as a
substitute for its timestamped transcript.

## Original Manim
The included original Manim scenes have an authored storyboard. After render-time
timestamps are reconciled, those scenes can support pause-and-question immediately
because their narration is authored in advance.
