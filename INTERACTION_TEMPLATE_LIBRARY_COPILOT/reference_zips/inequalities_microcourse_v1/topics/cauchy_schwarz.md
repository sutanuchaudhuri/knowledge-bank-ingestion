# Cauchy–Schwarz

Prerequisites: nonnegative squares, vectors/dot products or equivalent algebra,
proportionality, fraction manipulation.

Canonical form:
(sum ai bi)^2 <= (sum ai^2)(sum bi^2).

Vector form:
|<u,v>| <= ||u|| ||v||.

Equality iff the vectors are proportional.

Standard consequence:
(x+y+z)^2 <= 3(x^2+y^2+z^2).

Engel/Titu form, yi>0:
sum(xi^2/yi) >= (sum xi)^2/(sum yi).

Recognition cues:
- square of a sum;
- sum of products;
- sums x_i^2/y_i;
- reciprocal/fraction consolidation.

Misconceptions:
- MIS-CS-01: missing the outer square.
- MIS-CS-02: wrong equality condition.
- MIS-CS-03: Titu denominators not positive.
- MIS-CS-04: arbitrary pairings that do not reproduce the target.
