# Course dependency graph

Positive real arithmetic -> AM-GM -> Weighted AM-GM
Weighted AM-GM -> Jensen connection through concavity of log

Squares / vectors / dot product -> Cauchy-Schwarz

Symmetry + homogeneity + exponent notation -> Majorization -> Muirhead

Recommended order:
1. AM-GM
2. Weighted AM-GM
3. Cauchy-Schwarz
4. Jensen
5. Muirhead

Technique selection:
- AM-GM: positive terms, sum-product, fixed sum/product.
- Weighted AM-GM: unequal coefficients/exponents, target monomial matching.
- Cauchy-Schwarz: sums of products, sums of squares, Engel/Titu fractions.
- Jensen: repeated f(x_i), fixed mean, convex/concave function on full domain.
- Muirhead: symmetric homogeneous polynomial inequalities with comparable exponent tuples.
