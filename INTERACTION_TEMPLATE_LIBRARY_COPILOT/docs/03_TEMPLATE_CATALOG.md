## Diagnostic capabilities belong to templates

Example `TRANSITION_MATRIX_EDITOR_V1`:

```json
{
  "diagnostic_capabilities": [
    "ROW_SUM_INVALID",
    "NEGATIVE_PROBABILITY",
    "MISSING_TRANSITION",
    "WRONG_STATE_MAPPING",
    "ROW_COLUMN_CONVENTION",
    "ELEMENTWISE_POWER_CONFUSION"
  ]
}
```

Course author then maps those error signatures to canonical misconceptions.

Example `POLYNOMIAL_ROOT_COEFFICIENT_EXPLORER_V1`:

```text
VIETA_SIGN_ERROR
LEADING_COEFFICIENT_IGNORED
PAIRWISE_SUM_PRODUCT_CONFUSION
TRANSFORMED_ROOT_SYMMETRIC_SUM_ERROR
```

Example `FUNCTION_GRAPH_EXPLORER_V1`:

```text
CONVEX_DIRECTION_REVERSED

DOMAIN_VIOLATION
WEIGHT_NORMALIZATION_ERROR
```
